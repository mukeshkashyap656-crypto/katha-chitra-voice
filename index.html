⚙️ Pehli baar setup (token)

Token kaise banao (ek baar ka kaam):

1️⃣ Neeche wala 🔑 button dabao, GitHub khulega

2️⃣ Token name likho: voice. Expiration: lamba rakho (1 year)

3️⃣ Repository access → Only select repositories → katha-chitra-videos

4️⃣ Repository permissions mein ye teen Read and write karo: Issues, Contents, Actions

5️⃣ Generate token dabao, jo lamba token dikhe use copy karo

6️⃣ Wapas yahan aao, neeche box mein paste karo, Save karo dabao
